# Project instructions

Follow VERSIONING.md. Public product versions advance 0.01, 0.02, 0.03, etc. Every future small feature or fix release must increment the public version once, synchronize version.json, Flutter/internal build versions, documentation, artifact names and Release links. Never decrease Android versionCode or iOS build number. Never commit signing credentials or generated build outputs. Preserve native Android widget integration; implement other-platform features through the portable Flutter layer.
