# 公車報站&導乘 0.02

選好公車路線與方向，就能顯示站名、手動切站或自動播報。

## 開啟網頁版

**[開始使用公車報站&導乘](https://dandanteach.github.io/BusDaocheng/app/)**

使用瀏覽器操作，第一次播報請點選按鈕啟動聲音。
目前只更新網頁版；其他平台暫停建置，現有原始碼保留。


## 主要功能

- 選擇公車路線與方向，查看站名及路線圖。
- 播放中文、台語、客語與英語站名音檔。
- 設定自動切站間隔，隨時停止播報。
- 使用下車鈴與對外廣播。
- 調整主題、時鐘、背景照片。

桌面小工具目前僅提供 Android 版本。部分站名或對外廣播尚未提供錄音；路線圖僅供參考，實際乘車資訊請以營運單位公告為準。

## 怎麼使用？

1. 選擇路線與方向，按下「確認」。
2. 按「下一站」切換站名並播報，或啟動「自動播報」。
3. 在「設定」調整播放間隔及外觀。
